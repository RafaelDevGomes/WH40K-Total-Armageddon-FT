# WH40K Total Armageddon

O jogo fica em `Warhammer 40k Total Armageddon/`. Execute `Total Armageddon.exe`
para jogar ou use `Total Armageddon.bat` para instalar dependencias e gerar uma
nova versao.

## Organizacao

- `main.py`, `audio/`, `dados/` e `interface/`: codigo ativo do jogo.
- `sons/`, `musicas/`, `sprites/` e `video/`: recursos usados em tempo de execucao.
- `ferramentas/`: scripts de manutencao e empacotamento.
- `documentacao/`: contexto e documentos de estrutura.
- `artefatos/`: builds e distribuicoes geradas; nao e necessario para jogar.
- `legado/`: copias antigas mantidas apenas para referencia.
